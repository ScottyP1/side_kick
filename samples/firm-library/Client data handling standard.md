# Fabrikam Advisory – Client data handling standard

Effective 1 March 2026.

- Production client data never goes on laptops or personal devices. Use the client's own environments or the firm's approved secure workspace.
- Card data (PCI) is handled only in the client's PCI-certified systems; consultants never copy or export it.
- Client documents are kept for 7 years after the engagement ends, then deleted, unless the contract says otherwise.
- Report a suspected data incident to the firm's security team within 1 hour.
